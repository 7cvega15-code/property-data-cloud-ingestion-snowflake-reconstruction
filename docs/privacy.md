# Privacy & Provenance

This repository intentionally generalizes the enterprise work that inspired it.

## Not included

- Original vendor extracts
- Vendor contract or proprietary field names
- Employer system or platform names
- Production schemas, SQL, paths, credentials, endpoints, or storage details
- Real property/customer/account records
- Confidential source-to-target mappings

## Included

- Synthetic property records
- Generic cloud ingestion layers
- Common validation and source-to-target patterns
- Independently written SQL for portfolio demonstration
